# Learning Path — Macro for the Indian Investor

The full 27-day route, with the reasoning behind the sequence. Every row links to its page. The **Callbacks** column names which earlier concept each day retrieves — spaced roughly +5 and +14 days out from where a concept was introduced, so nothing you learn is allowed to quietly fade.

## Design rules this path obeys

- **One page = one load-bearing idea = 30–45 min.** If two ideas fought for a page, the page was split (that's why GDP takes Days 6 *and* 7).
- **Intuition first (Days 1–5):** everyday analogies only, no formal machinery.
- **Formalism in the middle (Days 6–21):** always re-grounded in the intuition already built.
- **Application and edges last (Days 22–27):** reading real releases, then where the model breaks.
- **Two Rest & Synthesize days (12, 26)** and **two Drill days (15, 24)** targeting the one bottleneck: *chaining a macro surprise through the mechanism to an asset move, and telling mechanism from narrative.*
- **A capstone (27)** on real, current Indian data.

1. **[Foundations](modules/01-foundations/overview.md)** (Days 1–5) — raw intuition, no formalism.

5. **[Reading the Real World](modules/05-reading-the-real-world/overview.md)** (Days 22–27) — releases, the RBI, second drill, breakage, capstone.
