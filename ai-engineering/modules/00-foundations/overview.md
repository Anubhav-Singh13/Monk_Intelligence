# Module 0 — Foundations & the Capability Layer

**What this module earns you:** the mental model the whole course runs on, plus discipline ① — **Foundation Model → Capability**.

You'll learn what AI engineering is (systems work around a rented model), the stateless-CPU / harness-as-OS frame, how to *choose* a model like an engineer (cheapest that clears your eval), and how to design around its *jagged* capability and failure modes.
