# Module 2 — Loop Engineering: Building the Loop

**What this module earns you:** the build half of discipline ⑤ **Loop → Feedback** — why agents loop at all, and a complete working agent in ~60 lines you own.

By the end you have a running ReAct loop that reasons, calls the tools from Module 1, and stops — with one deliberately naïve line that motivates the entire context module. (Loop *control* comes after context, since stopping and delegation depend on memory.)
