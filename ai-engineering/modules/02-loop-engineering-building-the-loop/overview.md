# Module 2 — Loop Engineering: Building the Loop

**What this module earns you:** the reason agents loop at all, and a complete working agent in ~60 lines you own line by line.

This is the first of two loop modules (the second, *Control & Orchestration*, comes after context — because stopping and delegation depend on memory). By the end you have a running ReAct loop that reasons, calls tools, and stops — with one deliberately naïve line that motivates the entire context module.
