# Module 3 — Context Engineering

**What this module earns you:** mastery of the course's central bottleneck — deciding what the model sees each call, out of everything it could. This is where most agent builders stall (context rot, overflow, lost state), and where this course invests most.

You'll learn that context is finite and positional, build the per-turn assembler, drill eviction under pressure, compress instead of delete, name the reusable patterns (agents, RAG, chat), give the agent memory that outlives the window, and ground it in external knowledge with RAG — then consolidate it all on a rest day.
