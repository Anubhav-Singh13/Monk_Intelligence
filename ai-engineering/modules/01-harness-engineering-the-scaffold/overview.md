# Module 1 — Harness Engineering: The Scaffold

**What this module earns you:** discipline ② **Prompt → Instructions** and the front half of ④ **Harness → Runtime** — the model-facing scaffold every agent needs before it can loop.

You'll learn to write prompts as programs, get output your code can trust (the parse boundary), give the model tools, and make the tool boundary a *trust* boundary. This is the first of two harness modules; the operations half comes later once you have a running agent to harden.
