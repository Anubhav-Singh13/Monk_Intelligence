# Module 1 — Harness Engineering: The Scaffold

**What this module earns you:** the model-facing scaffold every agent needs before it can loop — how to talk to the model as a program, get output your code can trust, and give the model hands it can't misuse.

This is the first of two harness modules (the second, *Reliability & Operations*, comes later once you have a running agent to harden). By the end you can turn a raw API into a safe, tool-capable, schema-validated single call.
